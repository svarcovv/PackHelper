# PackHelper

Сделал программу для тех, у кого сервер не скачивает ресурспак. Пак уже внутри проги.

## Установка

1. Скачай **PackHelper** из [последнего выпуска](https://github.com/svarcovv/PackHelper/releases/latest).
2. Полностью закрой майнкрафт.
3. Запусти программу и пройди три шага: выбери сборку, подтверди закрытие игры и установи пак.

Вручную включать рп не нужно.

## Обновления

При запуске программа проверяет свежий выпуск. Результат доступен на странице «Обновления». Кнопка **Проверить обновления** сравнивает версию приложения, встроенный пак и файл в выбранной сборке. Если есть новый выпуск, нажми **Обновить приложение**. PackHelper перезапустится с новым паком внутри. Перед установкой пака закрой майн.

После установки проверенного нового пака программа удаляет старые версии из его папки кэша. Остальные ресурспаки сохраняются.

Логи и пути к игре никуда не отправляются. Обновления проверяются по моей цифровой подписи разработчика.
