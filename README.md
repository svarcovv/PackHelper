# PackHelper

Сделал программу для тех, у кого Minecraft не скачивает ресурспак LavaBox. Пак уже внутри EXE, поэтому его можно установить без доступа к хостингу ресурсов.

## Установка

1. Скачай **PackHelper** из [последнего выпуска](https://github.com/svarcovv/PackHelper/releases/latest).
2. Полностью закрой Minecraft. Лаунчер можно оставить.
3. Запусти программу и пройди три шага: выбери сборку, подтверди закрытие игры и установи пак.
4. Зайди на **lavabox.fun** и разреши серверный пак.

Вручную включать ZIP не нужно. Программа для Windows 10 и 11, права администратора не требуются.

## Обновления

При запуске программа проверяет свежий выпуск. Результат доступен на странице «Обновления». Кнопка **Проверить обновления** сравнивает версию приложения, встроенный пак и файл в выбранной сборке. Если есть новый выпуск, нажми **Обновить приложение**. PackHelper перезапустится с новым паком внутри. Перед установкой пака закрой Minecraft.

После установки проверенного нового пака программа удаляет старые версии из его папки кэша. Остальные ресурспаки сохраняются.

Счётчик в верхней части окна показывает загрузки EXE с GitHub. Он обновляется при запуске, сохраняется для работы офлайн и не считает уникальных игроков или скачивания из Discord. Логи, пути к игре и сведения об игроках не отправляются.
