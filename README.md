# PackHelper

Сделал небольшую программу для тех, у кого Minecraft не скачивает ресурспак LavaBox. Вложил пак в саму программу: скачал один файл, установил и зашёл на сервер.

## Как установить

1. Скачай **PackHelper** из [последнего выпуска](https://github.com/svarcovv/PackHelper/releases/latest).
2. Полностью закрой Minecraft. Лаунчер можно оставить.
3. Запусти программу и выбери свою сборку.
4. Нажми **Установить ресурспак**.
5. Запусти игру, зайди на **lavabox.fun** и разреши серверный пак.

Вручную включать ZIP в меню ресурсов не нужно. Программа работает на Windows 10 и 11, права администратора не требуются.

Если сборка не нашлась или установка не помогла, открой [подробную помощь](HELP.md).

При обновлении пака выкладываю новый выпуск. Если сервер не может скачать обновление сам, запусти свежий PackHelper.
