# Как обновляю приложение и ресурспак

Код менять не нужно. Сборщик сам упакует новый ZIP в EXE и рассчитает контрольные суммы. Так пак остаётся доступен игроку без интернета.

1. Беру точный ZIP, который будет использовать сервер.
2. Скачиваю исходники PackHelper и запускаю `release.cmd` из распакованной папки.
3. Выбираю ZIP, указываю новую версию приложения и версию ресурспака, нажимаю **Собрать выпуск**.
4. На GitHub создаю новый выпуск с тегом **v + версия приложения**. Например, `v1.3.1`.
5. Прикладываю из папки `dist` файлы EXE, `update.json`, `pack-release.json` и `SHA256SUMS.txt`, затем публикую выпуск.

После этого игроки увидят обновление по кнопке в программе. Номер приложения увеличиваю при каждом выпуске, даже когда меняется только пак.

На сервере обновляю ссылку на ZIP и `pack.sha1`. UUID `pack.id` сохраняю. Значения должны совпадать с `pack-release.json`; ZIP после сборки не перепаковываю.

## Сборка командой

Windows 10 или 11, .NET Framework 4.8:

```powershell
.\test.ps1
.\build.ps1 -PackPath '.\LavaResurs.zip' -PackVersion '1.11.7' -AppVersion '1.3.1'
```

Версия тега важна: `update.json` содержит прямой адрес EXE из этого выпуска. Проверки установки и обновления запускаются в GitHub Actions.
